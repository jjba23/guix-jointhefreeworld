This is a [[https://guix.gnu.org/manual/en/html_node/Channels.html][GNU Guix channel]]
for the jointhefreeworld collection: Guile libraries, command-line programs,
Emacs packages, a GTK4 Wayland dock and the static site builder behind
[[https://jointhefreeworld.org][jointhefreeworld.org]].  Each package follows a
released tag of its project, so a pull gives the latest version rather than the
older copy the Guix channel happens to carry.

* Quick start

Append the channel to your channel list, keeping Guix itself:

#+begin_src scheme
  ;; ~/.config/guix/channels.scm
  (cons* (channel
          (name 'jointhefreeworld)
          (url "https://codeberg.org/jjba23/guix-jointhefreeworld")
          (branch "trunk"))
         %default-channels)
#+end_src

Then pull once and install what you need:

#+begin_src sh
  guix pull
  guix install maak ggg iter-vitae mutastructura
#+end_src

A checkout is enough for trying a package or hacking on the channel:

#+begin_src sh
  git clone https://codeberg.org/jjba23/guix-jointhefreeworld
  cd guix-jointhefreeworld

  guix install -L . maak
  guix shell -L . -m manifest.scm        # the whole collection
  guix build -L . -m manifest.scm        # build all of it
#+end_src

=-L .= adds the checkout to Guile's load path, which is what makes
=(jointhefreeworld packages)= resolvable before the channel has been pulled.

| =jointhefreeworld= |   1.0.1 | The jointhefreeworld.org site and builder |

=jointhefreeworld= installs the Emacs Lisp program that exports a checkout's Org
sources into a static site, together with the Emacs packages it uses.  It builds
the checkout you run it from:

#+begin_src sh
  git clone https://codeberg.org/jjba23/jointhefreeworld
  cd jointhefreeworld
  guix install jointhefreeworld
  jointhefreeworld-build              # writes ./public
  jointhefreeworld-serve              # serves ./public on port 50011
#+end_src

* Security and authentication

- Every source is fetched from its Codeberg repository and pinned by a SHA-256
  hash, so a moved tag cannot silently change what is built.
- The channel is authenticated with Guix's commit authentication:
  =.guix-authorizations= names the maintainer's OpenPGP key, =.guix-channel=
  names the =keyring= branch, and the introduction in =channels.scm= pins the
  first signed commit.  Guix verifies every fetched commit against the keys in
  =.guix-authorizations=.
- No deployment secrets, session keys, database files or =env.scm= files are in
  this channel.  The web services that need them are not packaged here; see
  below.

* What is not packaged

- *Artanis web services* (byggsteg, lucidplan, pingwing, wikimusic, torikomi)
  are deployment applications.  They read their configuration from a working
  tree and write a database and logs beside themselves, and a deployment needs
  its own =env.scm= and secrets.  They are run from their own checkouts.
- *symbanta* and *symbanta-dashboard* need a full Maven or npm dependency
  closure, which is not vendored.
- *free-alacarte* is a Haskell library and is not part of this channel.
- *heks-emacs*, *heks-linux* and *wolk-jjba* are personal configurations, not
  installable programs.  *private-notes* and *static-assets* are data.
  *wolkenschloss* has no public repository.

* Hacking on the channel

The repository is one module per kind of package:

#+begin_example
  .guix-channel                    channel metadata and primary URL
  .guix-authorizations             keys whose signatures are accepted
  manifest.scm                     every package, for `guix build -m'
  channels.scm                     an example channel list
  HACKING.org                      updating, adding, publishing, authenticating
  jointhefreeworld/
    packages.scm                   imports and re-exports all packages
    packages/
      guile.scm                    the Guile libraries
      applications.scm             the command-line programs
      emacs.scm                    the Emacs packages
      misc.scm                     heks-bash and lambdock
      site.scm                     the jointhefreeworld site builder
#+end_example

Every definition is an ordinary Guix package: an =origin=, a build system,
=arguments= and inputs, written the way packages are written in the Guix
repository itself.  There is no channel-specific macro to learn.

See [[file:HACKING.org][HACKING.org]] for updating a package, adding one, and publishing and
authenticating the channel.
